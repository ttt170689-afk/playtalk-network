# PlayTalk Network for Vercel

Сделал отдельную сетевую MVP-версию под **Vercel + Supabase**.

## Что уже есть
- регистрация по **нику + паролю**
- вход по **нику + паролю**
- список пользователей
- открытие диалога
- отправка текстовых сообщений
- realtime-обновление сообщений через Supabase
- простая online/last seen логика через `last_seen`

## Файлы
- `index.html` — интерфейс
- `styles.css` — стили
- `app.js` — логика клиента
- `config.js` — сюда вставляешь Supabase URL и anon key
- `config.example.js` — пример
- `supabase-schema.sql` — SQL-схема и политики
- `vercel.json` — базовая конфигурация Vercel

## Как запустить

### 1. Создай проект в Supabase
Создай новый проект.

### 2. Выполни SQL
Открой в Supabase: **SQL Editor** и вставь содержимое файла:
- `supabase-schema.sql`

### 3. Вставь ключи
Открой `config.js` и вставь:
- `supabaseUrl`
- `supabaseAnonKey`

Пример:
```js
window.PLAYTALK_CONFIG = {
  supabaseUrl: 'https://xxxxx.supabase.co',
  supabaseAnonKey: 'xxxxx'
};
```

### 4. Залей на Vercel
Проще всего так:
- залей папку `network-playtalk-vercel` в GitHub
- подключи репозиторий в Vercel
- Deploy

## Как работает вход по нику
Пользователь вводит:
- ник
- пароль

Внутри я делаю служебный email вида:
- `nick@playtalk.local`

То есть для юзера это выглядит как **логин/ник + пароль**.
